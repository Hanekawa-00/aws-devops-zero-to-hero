# VPC

想象一下，你想在云中建立一个私有、安全且隔离的区域来运行你的应用程序并存储数据。这就是 VPC 发挥作用的地方。

VPC 是你在云中创建的虚拟网络。它允许你拥有自己的互联网私有部分，就像在一个更大的网络中拥有自己的网络一样。在这个 VPC 中，你可以创建和管理各种资源，如服务器、数据库和存储。

把它想象成在更大的互联网中拥有自己的小"互联网"。这个虚拟网络完全与其他用户的网络隔离，因此你的数据和应用程序是安全且受保护的。

就像物理网络一样，VPC 有自己的一套规则和配置。你可以为 VPC 定义 IP 地址范围，并在其中创建称为子网的较小子网络。这些子网帮助你组织资源并控制它们之间的通信方式。

要将 VPC 连接到互联网或其他网络，你可以设置网关或路由器。它们充当进出 VPC 的流量的入口和出口点。你可以控制流量流向并设置安全措施来保护你的资源免受未经授权的访问。

使用 VPC，你可以控制你的网络环境。你可以定义访问规则、设置防火墙并配置安全组来规范谁可以访问你的资源以及它们如何通信。

默认情况下，当你创建 AWS 账户时，AWS 会为你创建一个默认 VPC，但这个默认 VPC 只是为了让你开始使用 AWS。你应该为应用程序或项目创建自己的 VPC。

## VPC 组件

以下功能帮助你配置 VPC 以提供应用程序所需的连接：

**虚拟私有云 (VPC)**

    VPC 是一个虚拟网络，与你会在自己的数据中心运营的传统网络非常相似。创建 VPC 后，你可以添加子网。

**子网**

    子网是 VPC 中的 IP 地址范围。子网必须位于单个可用区中。添加子网后，你可以在 VPC 中部署 AWS 资源。

**IP 寻址**

    你可以为 VPC 和子网分配 IPv4 和 IPv6 地址。你还可以将自己的公有 IPv4 和 IPv6 GUA 地址带到 AWS 并将它们分配给 VPC 中的资源，如 EC2 实例、NAT 网关和网络负载均衡器。

**网络访问控制列表 (NACL)**

    网络访问控制列表是一个无状态防火墙，在子网级别控制入站和出站流量。它在 IP 地址级别运行，可以根据你定义的规则允许或拒绝流量。NACL 为你的 VPC 提供了额外的网络安全层。
   
**安全组**

    安全组充当 VPC 中实例（EC2 实例或其他资源）的虚拟防火墙。它在实例级别控制入站和出站流量。安全组允许你定义基于协议、端口和 IP 地址允许或限制流量的规则。  

**路由**

    使用路由表确定来自子网或网关的网络流量被定向到哪里。

**网关和端点**

    网关将你的 VPC 连接到另一个网络。例如，使用互联网网关将你的 VPC 连接到互联网。使用 VPC 端点私下连接到 AWS 服务，无需使用互联网网关或 NAT 设备。

**对等连接**

    使用 VPC 对等连接在两个 VPC 中的资源之间路由流量。

**流量镜像**

    从网络接口复制网络流量，并将其发送到安全和监控设备进行深度数据包检测。

**中转网关**

    使用中转网关作为中央枢纽，在你的 VPC、VPN 连接和 AWS Direct Connect 连接之间路由流量。

**VPC 流日志**

    流日志捕获有关进出 VPC 中网络接口的 IP 流量的信息。

**VPN 连接**

    使用 AWS 虚拟专用网络 (AWS VPN) 将你的 VPC 连接到本地网络。
