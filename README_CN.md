# aws-devops-zero-to-hero

完整 YouTube 播放列表 - https://www.youtube.com/playlist?list=PLdpzxOOAlwvLNOxX0RfndiYSt1Le9azze

AWS 从零到英雄教程仓库，帮助 DevOps 工程师在 30 天内学习 AWS。本仓库包含项目、演示文稿、面试问题和实战示例。每一天的课程都将提供 AWS 服务的实时知识，让你能够学以致用，在 DevOps 场景中获得 AWS 实战技能。

## Day 1: AWS 简介

你将学习什么是私有云和公有云。为什么企业正在迁移到公有云，迁移到云有哪些优势。

此外，你将了解 AWS 的基础知识，包括核心服务及其在 DevOps 实践中的重要性。最后学习如何设置 AWS 账户并熟悉 AWS 管理控制台。

## Day 2: IAM (身份与访问管理)

你将探索 IAM，它用于管理对 AWS 资源的访问。你将学习如何创建 IAM 用户、组和角色，以及如何应用权限和安全最佳实践来确保正确的访问控制。

## Day 3: EC2 实例

你将深入了解 EC2，它在云中提供虚拟服务器。你将学习如何启动 EC2 实例、使用 SSH 连接到它们，并理解实例类型、安全组和密钥对等关键概念。

**你的第一个 AWS 项目**: 在 EC2 实例上部署一个简单的 Web 应用（如 Jenkins），并从 AWS 外部访问该应用。

## Day 4: AWS 网络 (VPC)

你将探索 AWS 网络概念，重点关注 VPC (虚拟私有云)。你将学习如何创建和配置 VPC、子网和路由表，从而能够设计和管理应用程序的网络基础设施。

## Day 5: AWS 安全

这一天强调 AWS 安全最佳实践。你将学习如何实施安全措施，如安全组、网络 ACL (访问控制列表) 和 IAM 策略，以确保 AWS 资源的机密性、完整性和可用性。

## Day 6: AWS Route 53

**项目**: 使用 Route 53 配置和管理域名。你将注册域名、设置 DNS 记录，并探索健康检查、路由策略和基于 DNS 的故障转移等高级功能。

## Day 7: 安全 VPC 设置与 EC2 实例

**项目**:

- 设计和配置 VPC:
    创建具有自定义 IP 范围的 VPC。
    设置公有和私有子网。
    配置路由表并关联子网。

- 实施网络安全:
    设置网络访问控制列表 (ACL) 以控制入站和出站流量。
    为 EC2 实例配置安全组，允许特定端口和协议。

- 部署 EC2 实例:
    在公有和私有子网中启动 EC2 实例。
    为实例配置安全组以允许必要的流量。
    创建并分配具有适当权限的 IAM 角色。

- 网络和路由:
    设置互联网网关，允许公有子网中的实例访问互联网。
    配置 NAT 网关或 NAT 实例，使私有子网中的实例能够进行出站互联网访问。
    创建适当的路由表并关联到子网。

- SSH 密钥对和访问控制:
    生成 SSH 密钥对并安全存储私钥。
    配置实例仅允许使用生成的密钥对进行 SSH 访问。
    实施 IAM 策略和角色来控制对 AWS 资源的访问和权限。

- 测试和验证设置:
    使用私钥 SSH 登录 EC2 实例并验证连接。
    测试不同子网中实例之间的网络连接。
    验证安全组规则和网络 ACL 设置。

通过实施此项目，你将获得设置安全 VPC 和 EC2 实例的实战经验，实施网络和路由，配置安全组和 IAM 角色，并确保正确的访问控制。该项目将让你从实践角度理解这些 AWS 服务如何协同工作，为你的应用程序创建安全且可扩展的基础设施。

## Day 11: AWS CloudFormation

这一天重点关注 AWS CodeCommit，一种托管源代码控制服务。你将学习如何在 CodeCommit 中设置 Git 仓库、与团队成员协作，并管理代码库的版本控制。

**项目**: 你将为团队项目配置 CodeCommit 仓库，包括设置访问控制和协作工作流程。

## Day 13: AWS CodePipeline

你将深入了解 AWS CodePipeline，一种完全托管持续交付服务。你将学习如何通过配置源代码、构建和部署阶段来构建端到端 CI/CD 流水线，自动化整个软件发布流程。

**项目**: 你将使用 CodePipeline 为应用程序部署创建 CI/CD 流水线，包括源代码集成、构建和自动部署到目标环境。

## Day 14: AWS CodeBuild

这一天重点介绍 AWS CodeBuild，一种完全托管的构建服务。你将学习如何在 CodeBuild 中配置构建项目、定义构建规范，并执行构建和测试流程。

**项目**: 你将为项目配置并运行 CodeBuild，包括定义构建规范并与其他 AWS 服务集成。

## Day 15: AWS CodeDeploy

你将探索 AWS CodeDeploy，一种用于自动化应用程序部署到各种计算环境的服务。你将学习如何创建部署组、配置部署策略，并在必要时执行自动回滚。

**项目**: 你将使用 CodeDeploy 为示例应用程序实施蓝绿部署策略，确保零停机部署和轻松回滚选项。

## Day 16: AWS CloudWatch

这一天重点介绍使用 AWS CloudWatch 监控 AWS 资源。你将学习如何创建告警、设置通知，并收集指标以深入了解应用程序和基础设施的健康状况和性能。

**项目**: 你将为应用程序的关键指标设置 CloudWatch 告警，定义适当的阈值条件，并配置通知操作。

## Day 17: AWS Lambda

这一天介绍 AWS Lambda 无服务器计算。你将学习如何创建和部署无服务器函数、基于事件触发它们，并利用 Lambda 构建可扩展的事件驱动架构。

## Day 18: AWS CloudWatch Events 和 EventBridge

这一天重点关注 AWS CloudWatch Events 和 EventBridge，这些是用于事件驱动架构的服务。你将学习如何创建事件规则、配置事件目标，并构建无服务器事件驱动工作流程。

**项目**: 你将使用 CloudWatch Events 和 EventBridge 构建无服务器事件驱动工作流程，演示基于事件的不同 AWS 服务集成和自动化。

## Day 19: AWS CloudFront

如果你从未听说过 CDN 或 CloudFront，不用担心，我们将从零开始逐步建立你的理解。到最后，你将精通这些技术。

**项目**: 你将配置一个 S3 存储桶来托管静态网站，并学习如何通过 CDN（即 AWS CloudFront）来处理对该网站的请求。

## Day 20: AWS ECR (弹性容器注册表)

你将探索 AWS ECR，一种完全托管的容器注册表，用于存储和管理容器镜像。你将学习如何向 ECR 推送和拉取 Docker 镜像，实现与 ECS 和其他容器服务的无缝集成。

**项目**: 你将构建一个 CI/CD 流水线，自动构建、推送并将 Docker 需部署到 ECR，确保容器镜像管理的流畅性。

## Day 21: AWS ECS (弹性容器服务)

这一天重点介绍 AWS ECS，一种完全托管的容器编排服务。你将学习如何使用 ECS 运行和管理容器，包括创建任务定义、管理服务，以及使用自动扩展功能进行扩展。

**项目**: 你将使用 ECS 部署多容器应用程序，配置自动扩展策略，并确保高可用性和高效资源利用。

## Day 22: AWS EKS (弹性 Kubernetes 服务)

这一天介绍 AWS EKS，一种完全托管的 Kubernetes 服务。你将学习如何使用 EKS 部署和管理 Kubernetes 集群，包括启动工作节点、配置网络，以及使用 Kubernetes 清单部署应用程序。

**项目**: 你将使用 Kubernetes 清单在 EKS 上部署示例应用程序，演示在托管 Kubernetes 服务上运行容器化应用程序的能力。
