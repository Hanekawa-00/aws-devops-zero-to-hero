# IAM

AWS IAM (身份与访问管理) 是 Amazon Web Services (AWS) 提供的一项服务，帮助你管理对 AWS 资源的访问。它就像是你的 AWS 账户的安全系统。

IAM 允许你创建和管理用户、组和角色。用户代表需要访问你的 AWS 资源的个人或实体。组是具有相似访问需求的用户集合，便于权限管理。角色用于向外部实体或服务授予临时访问权限。

通过 IAM，你可以通过策略控制和定义权限。策略以 JSON 格式编写，指定在特定 AWS 资源上允许或拒绝的操作。这些策略可以附加到 IAM 实体（用户、组或角色），以授予或限制对 AWS 服务和资源的访问。

IAM遵循最小权限原则，即用户和实体仅获得其任务所需的必要权限，从而最大限度地减少潜在的安全风险。IAM 还提供多因素认证 (MFA) 等安全功能，以及用于跟踪用户活动和权限变更的审计追踪功能。

通过使用 AWS IAM，你可以有效管理和保护对 AWS 资源的访问，确保只有授权人员拥有适当的权限，并记录所有操作以便于问责和合规。

总之，IAM 是 AWS 安全的重要组成部分，提供对 AWS 账户和资源访问的精细控制，降低未经授权访问的风险，帮助维护安全的环境。

## IAM 的组成部分

用户: IAM 用户代表与你的 AWS 资源交互的个人人员或实体（如应用程序或服务）。每个用户都有唯一的名称和安全凭证（密码或访问密钥），用于身份验证和访问控制。

组: IAM 组是具有相似访问需求的用户集合。你可以将权限分配给组，而不是单独管理每个用户的权限，从而简化访问控制管理。用户可以根据需要添加或移除到组中。

角色: IAM 角色用于授予对 AWS 资源的临时访问权限。角色通常由需要代表用户或其他服务访问 AWS 资源的应用程序或服务使用。角色具有关联的策略，定义该角色允许的权限和操作。

策略: IAM 策略是定义权限的 JSON 文档。策略指定可以在 AWS 资源上执行的操作以及这些操作适用的资源。策略可以附加到用户、组或角色以控制访问。IAM 提供 AWS 管理策略（由 AWS 维护的预定义策略）和客户管理策略（由你创建和管理的策略）。
